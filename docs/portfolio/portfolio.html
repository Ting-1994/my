1. 项目概览

本项目面向营销组合建模（MMM）与投放优化场景，基于 Robyn 模型结果，构建了覆盖模型配置 → ROI 分析 → 预算分配 → 场景模拟 → Dashboard 可视化 → AI 对话分析的一体化工作台。目标是让业务团队无需编写代码，即可在统一界面完成数据驱动的投放决策。

2. 分析模块详解

2.1 Settings —— 模型与基础配置

  • 按地区加载 Robyn 模型 JSON 与配套 CSV（pareto 超参数、聚合结果、分解矩阵等）。
  • 展示输入数据、模型性能与超参数，是其余模块的统一数据入口。

2.2 Optimization —— 场景优化

  • 场景一：通过优化投资缩小销售差距。
  • 场景二：在预算限制下最大化销售额。
  • 输出投放建议图表与结果表格，直接支持预算决策。

2.3 ROI Analysis —— 响应与回报分析

  • 渠道响应曲线与边际 ROI 曲线，识别各渠道饱和点与增量空间。
  • 多方案对比，支持数据下载用于二次分析。

2.4 Allocator —— 预算分配

  • 基于 Robyn allocator 做预算分配，评估渠道投入区间与分配结构。

2.5 Dashboard —— 结果看板

  • 汇总关键业务表现与渠道贡献，支持按地区切换。
  • 修复增量销售与同比口径不一致问题，改造 offset 列为动态数据适配，保证指标口径一致。

2.6 Simulator —— 预测模拟器

  • 左侧参数面板 + 右侧结果区；动态参数分组、滚动输入与结果联动。
  • 参数重置、配置导出/导入，便于复现与分享假设方案。

2.7 AI Assistant —— 对话分析

  • LLM 做意图识别与分析结论润色，降低业务同学使用门槛。
  • 多轮问答与会话历史持久化，旧版存储结构自动迁移；回答可跳转到相关分析模块。

3. 工程架构与质量

.
├─ app.R                   主入口：模块装配、鉴权、全局状态
├─ app_simulator.R         独立模拟器入口（实验/验证）

└─ rsconnect/              shinyapps.io 部署记录

工程实践

  • 模块化：UI/Server 分离，按业务模块拆分，便于维护与扩展。
  • 权限控制：登录鉴权 + 角色化菜单与页面访问控制（动态菜单渲染）。
  • 数据适配：按地区、版本组织模型文件，地区映射集中维护。
  • 安全：API Key 通过 .Renviron 环境变量注入，不硬编码。
  • 可复现：renv 锁定依赖；提供独立模拟器入口用于实验验证。
